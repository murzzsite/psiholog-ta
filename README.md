# Психолог ТА (транзактный анализ)

Лендинг, HTML/CSS/JS без сборщиков. Заявки: форма `#leadForm` -> Cloudflare Worker `lead-relay` -> Telegram (ref `Y5SXM5AYV8`).

- Идея: три круга эго-состояний Берна (Р, В, Д) — мотив всей страницы; живой блок «Разберите реплику» (дополнительные и пересекающиеся транзакции).
- Картинки (общественное достояние, Wikimedia Commons, кредиты в подвале): Ангуиссола «Шахматная партия», Шеннон «Мать и дитя», фото ребёнка N. E. Lusher, занавес Национального театра (Гынайс).
